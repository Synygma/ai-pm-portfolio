# Review checklist

(A) = checked by scripts/check_post.py · (M) = check manually

## Before writing
- (M) Topic is in one of the 3 lanes
- (M) There is an evidence pack: a headline number, a named real-world example, a caveat, all from verified recent sources
- (M) The takeaway can be stated in one sentence
- (M) The format fits: text for opinions, document for frameworks, image for a real artifact

## Hook
- (A) Core idea lands in ≤140 characters / first 2 lines
- (M) Contains a number, named tool or named situation
- (M) Tension opens above the fold and resolves below it
- (A) No hype/bait phrases

## Body
- (M) Context line answers "why trust me?"
- (A) Paragraphs ≤3–4 lines; not a wall of one-liners
- (A) Text post ~900–1,500 chars (or deliberately short with a sharp finding)
- (M) At least one failure, caveat or trade-off
- (M) Model/tool names and dates are specific
- (M) Reads like a person, not a template
- (A) No placeholders: the post is final and copy-paste ready
- (M) Every number, company, event and quote traces to a source opened during research, with matching date and wording
- (A/M) No invented personal experience ("we tested", "my team") unless the user supplied it

## Close
- (M) Takeaway sentence is quotable
- (M) CTA asks for experience, not agreement (or a clean statement ending)
- (A) No keyword-for-DM, no stacked follow/repost asks
- (A) 0–2 hashtags
- (A) No links in the body (they go in the first comment)

## Posting notes to give the user
- Post Tue–Thu at a time when you can reply for 60–90 minutes
- Not within 24h of your previous post
- Post the first comment right away
- Reply to substantive comments with a follow-up question
- After 7 days, log impressions, comments, saves and comments per 100 reactions against your own median
