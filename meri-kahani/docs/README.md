# Meri Kahani — Documentation Index

**Meri Kahani** is a free website where Indian parents enter their child's details and get a
personalised **bedtime story** or **fun poem** in **English, Hindi or Marathi**, with the child as the hero.

- **Live:** https://meri-kahani-nine.vercel.app
- **Status (2026-11-03):** MVP built and deployed on Vercel (free Hobby plan) as a prototype.

All documents are in simple English. Anything not built yet is marked **Planned**.
No document contains API keys or secrets.
